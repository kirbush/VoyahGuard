# APK

`VoyahGuard-Lite-0.5.apk` — подписанная release-сборка `0.5-lite-alpha`: запись полного кадра, сегменты, настраиваемое хранение и опциональный Power Hold. Контрольная сумма находится в `SHA256SUMS`. Предыдущие `Voyah-Camera-0.3.apk` и `Voyah-Camera-0.4.apk` сохранены как исторические релизы.

Просмотр и запись рассчитаны на систему, указанную в [README](../README.md). Режим выбирается в штатном 360; четыре ракурса и Power Hold требуют проверки на автомобиле. Исходники не содержат OEM-библиотек распознавания, прежнего native-переключателя или зависимости от NDK.

APK подписан ключом разработки, не включённым в репозиторий. Debug APK из GitHub Actions использует другой ключ. Для обновления без удаления приложения подписи должны совпадать.
