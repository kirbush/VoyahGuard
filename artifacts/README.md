# APK

`VoyahGuard-0.8.apk` — подписанная release-сборка `0.8-beta`: режим тревоги (голос, красная подсветка салона, фары) с расстоянием по сторонам, три вида записей, дата и время на видео, удаление записей и логи для тестеров. Контрольная сумма находится в `SHA256SUMS`. Предыдущие APK сохранены как исторические релизы.

Просмотр и запись рассчитаны на систему, указанную в [README](../README.md). Ограничения перечислены там же и в примечаниях к выпуску.

APK подписан ключом разработки, не включённым в репозиторий. Debug APK из GitHub Actions использует другой ключ, а release APK из GitHub Actions не подписан. Для обновления без удаления приложения подписи должны совпадать.
