# VoyahGuard — Сторож Lite 0.5-alpha

Первая Lite-версия для записи на стоянке на прошивках ОД без штатного Sentry. Прежний проект VoyahCamera360DVR переименован в VoyahGuard. Нужный режим выбирается вручную в штатном 360; приложение сохраняет весь поступающий AVM-кадр.

## Возможности

- Запись при открытии включена по умолчанию для новой установки; сохранённое предпочтение предыдущей установки сохраняется. Автозапись можно отключить в настройках. Стоп, возврат из проигрывателя и пересоздание Activity не включают запись снова.
- Один составной кадр в каждом MP4/H.264 без звука, фрагменты 1/3/5 минут. Камера и кодировщик не перезапускаются на границах; новые файлы начинаются с ключевого кадра.
- Файлы в Android/data/local.codex.voyahcameralab/files/Movies/Sentry. Есть список записей, просмотр и экспорт в выбранную папку. Старые ролики Movies/VoyahCamera360DVR не удаляются.
- Циклическое хранение по умолчанию, альтернатива «Остановить запись», порог общей занятости накопителя 50–95% (default90%), резерв128MiB. Удаляются только старые собственные завершённые ролики; текущий и последний завершённый сохраняются. Если место не освобождается, запись завершается.
- Опциональный Power Hold, выключенный по умолчанию; длительность30–180минут, default120. Собственный ограниченный helper использует установленный штатный SDK и существующий root, без VoyahTweaks и OEM-библиотек в APK.
- Раздельные состояния запроса, подготовки и активности Power Hold; сохранение ранее включённого режима, журнал владения, завершение MP4 до отпускания собственного питания. Замеченная штатная отмена не вызывает повторного включения.
- Новая векторная иконка со щитом и камерой. Удалены неиспользуемые кнопки/инвентаризация, front/rear native helper и зависимость от NDK. Вертикальный старый профиль коррекции зелёного низа сохранён отдельной экспериментальной опцией, выключенной по умолчанию.
- Для Obtainium выпуск опубликован как Latest с одним release APK; включение prerelease и фильтры APK не требуются. Название версии остаётся alpha и не означает подтверждённой аппаратной совместимости.

## Ограничения alpha

Четыре отдельных ракурса появятся в записи только если их отдаёт выбранный штатный режим. Это ещё предстоит проверить на автомобиле. Обычный кадр «вид сверху + выбранная камера» не называется четырьмя независимыми ракурсами.

Power Hold исследован статически по ОД13.1 и сопоставлен с ранее сохранёнными SDK/сервисом. Работу root, подготовку/активацию после запирания и отключение на машине ещё не проверяли. Отправленный Binder-запрос не является подтверждением ECU. При недоступном API приложение показывает отдельный статус; запись доступного видеопотока может продолжаться.

Открытое окно обязательно: при скрытии камера освобождается. Распознавания, облака, SMS, пробуждения автомобиля и обхода ограничения камер в движении нет. Неожиданное отключение может повредить последний незавершённый файл. При удалении приложения его папка данных может удалиться — экспортируйте важные записи.

## Совместимость обновления и проверки

Application ID local.codex.voyahcameralab сохранён. Release APK подписан тем же ключом обновлений, что0.4-alpha; подписи сравниваются перед публикацией. Системные файлы, скорость и interlock не меняются.

Локально выполняются corePolicyTest, assembleDebug, assembleDebugAndroidTest и assembleRelease, проверка подписи и состава APK. Хостовый symlink-тест может быть пропущен из-за ограничений Windows. Инструментальные тесты только компилируются; аппаратная совместимость, реальные четыре ракурса и Power Hold этой сборкой не подтверждаются.
