# VoyahGuard — Сторож Lite 0.5.1-alpha

Исправительный выпуск по итогам аудита кода 0.5-alpha. Новых функций нет. Application ID и ключ подписи прежние, установка поверх 0.5-alpha не требует удаления приложения.

## Запись и жизненный цикл

- Смена ночного режима, языка, размера окна или другой конфигурации больше не пересоздаёт окно и не останавливает идущую запись. Раньше, например, переключение день/ночь на оставленной машине завершало запись без повторного запуска.
- Открытие значком уже запущенного приложения теперь считается новым открытием и запускает автозапись, как описано в инструкции. Раньше автозапись срабатывала только при первом запуске процесса. Если запись уже идёт, повторное нажатие на значок её не прерывает.
- Отказ в доступе к камере больше не вызывает бесконечный показ системного диалога. Запрос повторяется только по кнопке «Старт» или при новом открытии.
- Медленный, но живой видеопоток ниже 6 кадров/с больше не принимается за остановившийся. Раньше такая запись завершалась через несколько секунд.
- Причина остановки по заполнению памяти показывается обычным текстом, а не как ошибка GPU.

## Хранение и просмотр

- Если том заполнен чужими данными и удаление своих старых роликов всё равно не поможет, ролики теперь сохраняются. Раньше циклический режим стирал весь архив, кроме последнего ролика, и всё равно не начинал запись.
- Брошенные фрагменты .mp4.part прошлых сессий, например после отключения питания, больше не копятся бесконечно: при нехватке места в циклическом режиме они удаляются первыми. Режим «Остановить запись» по-прежнему ничего не удаляет.
- Сторонние проигрыватели, запрашивающие дополнительные поля файла, больше не получают исключение. Раньше это могло приводить к сбою проигрывателя при открытии ролика.
- Прерванный экспорт больше не оставляет неполный файл в выбранной папке.

## Power Hold

- Незавершённый журнал прошлой загрузки ГУ снимается автоматически по чтению статуса, без команд автомобилю. Раньше потеря питания при активном удержании навсегда блокировала Power Hold в приложении, а единственным выходом была очистка данных, стирающая и записи.
- Подтверждение отключения теперь повторяется чтением статуса до минуты после «Стоп». Раньше запаздывание штатного статуса показывалось как ошибка и блокировало Power Hold в следующей записи.
- Если при «Стоп» состояние не удалось прочитать или длительность ещё не обновилась, отключение повторяется, так как команда не отправлялась.

## Сборка

GitHub Actions теперь собирает release APK и выполняет release lint для каждого коммита. Проверка выпуска сверяет имя APK с версией приложения.

## Ограничения и проверки

Выполнены JVM-тесты правил (corePolicyTest), сборка и lint в GitHub Actions, проверка подписи и состава APK. На автомобиле 0.5.1-alpha, как и 0.5-alpha, не проверялась: поведение жизненного цикла, запись и Power Hold подтверждены только анализом кода и тестами правил. Новый журнал Power Hold и подтверждение отключения проверяются на ГУ по обычному плану. Ограничения alpha из 0.5 сохраняются: нужный режим выбирается в штатном 360, окно должно оставаться на экране, Power Hold требует имеющегося root и не подтверждён на автомобиле.
