# VoyahGuard — Сторож Lite

Запись видеопотока штатных камер Voyah Free на стоянке для прошивок ОД без штатного Sentry. Версия **0.5-lite-alpha**. Нужный режим пользователь выбирает вручную в штатном 360, затем открывает приложение.

В публичном репозитории находятся исходники приложения, Gradle-сборка, тесты и подписанные релизные APK. Возможности, настройки и ограничения описаны ниже.

**[Скачать Lite 0.5-alpha](https://github.com/kirbush/VoyahGuard/releases/download/v0.5-lite-alpha/VoyahGuard-Lite-0.5.apk)** · [Релизы](https://github.com/kirbush/VoyahGuard/releases)

## Как пользоваться

1. На стоящем автомобиле выберите нужный режим в штатном 360.
2. Откройте Сторож Lite и убедитесь, что показано «Запись» и идёт таймер.
3. При уходе из машины оставьте приложение на экране. Если нужен Power Hold, заранее включите его управление в настройках приложения.
4. Вернувшись, нажмите «Стоп». После сохранения откройте «Записи» для просмотра или экспорта.

По умолчанию приложение сохраняет **весь поступающий кадр** без обрезки, переключения переднего/заднего вида и распознавания. Четыре ракурса появятся в записи только если их действительно отдаёт выбранный штатный режим. На прошивках ОД это ещё требует проверки; обычный кадр «вид сверху + выбранный ракурс» не объявляется четырьмя независимыми видами.

В дополнительных настройках сохранён экспериментальный старый профиль «Убрать зелёный низ». Он выключен по умолчанию и включается только вручную при фактическом нижнем заполнении. Для поддерживаемого AVM-профиля записываются верхние60% с прежней геометрией; неподдерживаемый источник остаётся полным кадром. Автоматического определения зелёной области нет; применимость к новому режиму проверяется на машине.

## Запись и настройки

В новой установке автозапись при открытии включена; сохранённая настройка предыдущей установки сохраняется. Её можно выключить для просмотра и ручного старта. «Стоп», возврат из проигрывателя и восстановление Activity не включают запись повторно.

Видео — MP4/H.264 без звука, 6 Мбит/с. По умолчанию создаются минутные фрагменты; доступны 3 и 5 минут. Новый файл начинается с ключевого кадра без перезапуска камеры и кодировщика.

Ролики лежат в папке данных приложения:

    Android/data/local.codex.voyahcameralab/files/Movies/Sentry/

«Записи» показывает завершённые файлы и позволяет воспроизвести их или сохранить в другую папку. Папка данных может удалиться при удалении приложения; важные ролики экспортируйте. Старые записи в Movies/VoyahCamera360DVR не перемещаются и не удаляются.

По умолчанию включено удаление самых старых собственных роликов при заполнении накопителя. Можно выбрать «Остановить запись», тогда автоматического удаления нет. Порог общей занятости тома — 90%, выбор 50–95%; дополнительно сохраняется физический резерв 128 MiB. Чужие файлы, незавершённый фрагмент и последний завершённый ролик не удаляются. Если старые собственные файлы не освобождают достаточно места, запись завершается.

При скрытии окна, ошибке камеры и прекращении кадров запись завершается, камера освобождается. Автоматических повторных захватов нет. Внезапное отключение питания может повредить последний незавершённый фрагмент; уже завершённые MP4 остаются отдельными файлами.

## Power Hold

Управление Power Hold **выключено по умолчанию**: для записи, когда пользователь остаётся в салоне, оно не требуется. Предлагаемая длительность — 120 минут, доступны штатные 30/60/90/120/150/180 минут. Настройки питания и длины фрагмента применяются к следующей записи, настройки памяти — сразу.

Функция требует уже имеющегося su и совместимых установленных Qinggan API. Приложение не устанавливает root, не включает автозарядку двигателем и не использует VoyahTweaks. Собственный helper ограничен штатными полями Power Hold, проверяет известные версии файлов, P и SOC; произвольных автомобильных команд нет.

«Запрошен», «Подготовлен» и «Активен по штатному статусу» различаются. Отправка запроса сама по себе не доказывает фактическое удержание питания. Ранее включённый штатный режим приложение не присваивает себе и не отключает; собственное удержание отпускается после завершения видео. Неизвестное состояние, ошибки частичного запроса и незавершённый журнал явно показываются. Повторное включение после штатной отмены не выполняется.

Интерфейс установлен статически по ОД 13.1 и сравнен с ранее сохранённым SDK, но root-доступ, запросы, запирание и отключение **ещё не проверены на автомобиле**. При недоступном управлении запись видеопотока остаётся возможной с отдельным сообщением о Power Hold.

## Совместимость

Целевая система — Voyah Free H97X, V3 Restyling российской сборки, Sport Plus, Android 11 / API 30. На ранее исследованном ГУ отдельно менялась обработка AVM-буфера HAL; APK системные файлы не меняет. Применимость к другим моделям и прошивкам не подтверждена.

Camera2 ID 1 — вход составного AVM-потока; номера входов не являются обозначениями четырёх наружных камер. Ограничение доступности потока в движении этим приложением не устраняется; Lite предназначена для стоянки. Распознавание, облако, SMS и аппаратный цикл сна не включены.

## Сборка и установка

Требуются JDK 17, Android SDK platforms;android-30 и build-tools;35.0.0. Версии Gradle/AGP закреплены, Wrapper включён. Собственных C/C++-модулей, OEM-библиотек и зависимости от NDK в Lite нет.

    ./gradlew :app:corePolicyTest :app:assembleDebug :app:assembleDebugAndroidTest :app:assembleRelease

Windows: gradlew.bat с теми же задачами. Debug APK — app/build/outputs/apk/debug/app-debug.apk; release APK — app/build/outputs/apk/release/app-release.apk при настроенной подписи. SDK задаётся ANDROID_HOME или локальным local.properties.

Application ID и Activity сохранены:

    local.codex.voyahcameralab/.MainActivity

Для собственного ключа доступны VOYAH_SIGNING_KEYSTORE, VOYAH_SIGNING_STORE_PASSWORD, VOYAH_SIGNING_KEY_ALIAS и VOYAH_SIGNING_KEY_PASSWORD. Обновление существующей установки требует той же подписи. CI debug APK может иметь другую подпись. Ключи, OEM-бинарники и личные материалы не коммитятся.

Метаданные и SHA-256 подготовленного релиза находятся в releases/latest.json и artifacts/SHA256SUMS. Workflow Publish release проверяет их и публикует APK при обновлении releases/ в main; существующий релиз не перезаписывается.
